# NAYA SAVERA

### AI-Assisted Urine-Strip Health Screening System

NAYA SAVERA is a smart public-health screening prototype designed to make basic health screening more accessible through automated urine-strip analysis.

The system combines automated sample handling, camera-based strip detection, and AI/ML-assisted analysis to generate a simple digital screening report.

> **Prototype developed as a student innovation project.**

---

## Problem

Many health conditions are detected only after symptoms become noticeable or serious.

Traditional health screening can be:

- Time-consuming
- Expensive
- Difficult to access regularly
- Dependent on visiting a healthcare facility

NAYA SAVERA explores how automated screening kiosks could bring preliminary health screening into everyday public spaces.

---

## Solution

NAYA SAVERA is designed as an automated health-screening kiosk that:

1. Collects a urine sample
2. Uses a urine test strip
3. Captures the strip using a camera
4. Analyses the strip image using AI/ML techniques
5. Generates a digital screening report

The system is intended for **preliminary screening**, not as a replacement for professional medical diagnosis.
